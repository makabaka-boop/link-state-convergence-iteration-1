# 链路状态路由模拟器

一个确定性的离散事件（tick）模拟器：2～8 个路由器组成的网络中，每个路由器
**只依据自己的链路状态库 (LSDB)** 计算下一跳，不能读取网络全局真值。链路变化
产生带来源与递增序号的通告 (LSA)，传输层可对通告做延迟、复制、乱序、丢弃；
旧序号通告不能覆盖较新状态；分区期间明确显示不可达；恢复连通且消息停止丢失后
必然收敛。

另支持**可撤销的过境排空（transit drain）**：维护某台路由器时，由它在本地 LSA
中随递增序号宣告过境资格，其它节点仍可把它作为目的地，却不得再借它中转到第三台
设备；通告者自身仍能作为起点；撤销排空后恢复按费用与完整路径字典序选路。

## 运行

```bash
# 6 节点演示场景（涨价 → 分区 → 过期通告注入 → 重连收敛），逐 tick 文本输出
python3 -m linkstate.cli

python3 -m linkstate.cli --verbose          # 打印每条 SEND/RECV/DROP
python3 -m linkstate.cli --ticks 30 --json out.json   # 导出完整结构化记录

# 过境排空演示（默认场景 + tick24 排空 R3、tick28 撤销；默认场景输出不变）
python3 -m linkstate.cli --drain-demo

# 测试（37 个用例 + 两套独立参照交叉验证）
python3 -m unittest discover -s tests -v
```

## 模块

| 文件 | 职责 |
| --- | --- |
| `linkstate/lsa.py` | 通告：`origin`（来源）+ `seq`（严格递增）+ 直连链路完整快照 + `transit`（过境资格） |
| `linkstate/dijkstra.py` | 路由器侧最短路：标签为 `(总费用, 完整ID路径元组)`，费用优先，并列按完整路径字典序；排空节点删出边、留入边 |
| `linkstate/router.py` | 本地 LSDB、序号裁决（new/stale/dup）、逐跳心跳老化闭包、排空/撤销、路由表 |
| `linkstate/transport.py` | 有损传输：随机延迟（产生乱序）、复制、按窗口概率丢弃、精确过滤、分区丢弃 |
| `linkstate/network.py` | 逐 tick 模拟器：事件（含 drain/undrain）、泛洪（水平分割）、周期补发、快照输出 |
| `linkstate/cli.py` | 演示场景（`--drain-demo` 为排空演示）与文本/JSON 输出 |
| `tests/reference.py` | **独立**参照：无约束与受构各两种写法（定点松弛 + DFS 全枚举）互相交叉验证 |
| `tests/helpers.py` | 用活动拓扑真值核对每个路由器实际路由；受构真值（含排空集合）核对与不变量 |
| `tests/test_linkstate.py` | 收敛、字典序并列、过期通告、涨价、分区/重连、补发兜底等 16 个用例 |
| `tests/test_transit_drain.py` | 过境排空：到达排空点、绕行、并列、咽喉阻断、过期通告、撤销、有损/分区收敛、非法事件原子性、旧输出不变等 21 个用例 |

## 每个 tick 的输出

每个 tick 记录包含：

- `events`：本 tick 的拓扑事件（涨价 / 切断 / 恢复 / 丢弃窗口 / 注入）；
- `messages`：每条 `send` / `deliver` / `drop`，含来源、去向、LSA（origin、seq、
  links）、延迟、复制/补发标记、接收端裁决（`new` / `dup` / `stale`）或丢弃原因；
- `routers`：每个节点的 `lsdb`（各来源最新 LSA）与 `routes`
  （目的地、下一跳、费用、完整路径；不可达时 `next_hop=null, cost=-1`）。

## 关键设计

### 序号裁决（旧不得覆盖新）

`Router.receive` 对每个来源只保留最高序号：低序号一律 `stale` 拒绝；
同序号内容不一致（链路快照**或过境资格位**被篡改，即伪造/重放）也拒绝；
完全相同才是 `dup`。新旧判断只发生在接收端，传输层对内容无感知——因此过期
通告（无论旧链路还是旧的过境资格）即使穿过有损传输也无法污染状态库。

### 过境排空（可撤销的维护事件）

维护路由器 X 时，目标是“**全网仍可访问 X 自身，但流量不再经 X 去往第三台
设备**”。该约束完全由各节点凭本地 LSDB 裁决，不存在可读的全局维护标志：

- X 调用 `drain()` 签发序号 +1 的新 LSA，其中 `transit=False`（与链路快照
  一体泛洪）；`undrain()` 再签发序号 +1、`transit=True` 的通告撤销。
- 收到通告的节点重建有向图时，对排空节点 d **删除 d 的全部出向边、保留
  其它节点指向 d 的入向边**：路径因此不能再“穿过” d，但仍能在 d 结束
  （d 可作目的地）；算路源点自己排空时其出边保留（它仍能作起点）。
- 排空只影响中转，**不影响新鲜度闭包与双向边规则**：d 的链路依旧双向声明、
  心跳照常，d 不会被误判为不可达，只是身后只允许经其它路径到达。
- 迟到的低序号通告或同序号异内容（含把 `transit` 篡回 `True`）一律 `stale`，
  无法恢复旧资格；撤销后排空期旧 LSA（`transit=False`）回灌也不能重新抹掉
  已恢复的过境资格。
- 传输延迟/复制/丢包/分区期间各节点认识允许暂时不同（例如分区对端暂时学不到
  排空位）；恢复连通且消息停止丢失后，借泛洪与周期补发必然收敛到同一结果。
- 非法事件（未知节点、重复排空、未排空却撤销）在产生任何通告/消息**之前**
  抛错，通告、LSDB、消息轨迹均不发生部分更新。
- 撤销排空后恢复原裁决：费用优先，并列按完整路径字典序。

### 字典序并列

费用相同时按**完整路由器 ID 路径**的元组字典序选路，例如
`("R1","R2","R4") < ("R1","R3","R4")`。Dijkstra 直接以 `(费用, 路径元组)`
做松弛标签即可，正费用下最优子结构成立。

### 分区与老化（为什么只有递增序号还不够）

网络分区时，一侧路由器会永久持有对端最新已知 LSA（对端新 LSA 物理上无法跨越
分区送达），而周期补发会让这些旧副本在本侧反复出现。为此模拟了逐跳心跳老化：

- 每条 LSA 记录“最近一次从哪个邻居听到”（周期补发持续刷新）；
- 建图只采用**两端 LSA 双向声明一致**的边（任一端的新 LSA 删除该边后，
  旧副本无法拼出跨越分区的幽灵路径）；
- 新鲜集合从自己出发沿“双向声明一致 + 两端心跳均在 MaxAge 内经新鲜方向
  听到”的边做闭包；闭包外的已知节点显式标记**不可达**，LSA 仍保留在库中；
- 重连后双向心跳恢复，闭包在数个 tick 内重新覆盖全网。

### 收敛保障

- 链路变化时两端立即签发新序号 LSA 并水平分割泛洪；
- 所有路由器周期性（默认每 5 tick）向每个活动邻居补发**当前已知全部状态**，
  即使初始通告全丢、泛洪副本被丢，最终也会收敛；
- 重连事件同时把丢包概率置零，对应“消息停止丢失后须收敛”。

## 测试覆盖

- 2～8 节点（含 2 节点最小图、8 节点环+弦）及多组 3～7 节点随机连通图，
  有损传输下最终结果逐项等于独立参照；
- 并列费用的字典序裁决（并列点在第一跳之外的情形）；
- 过期通告：直接裁决拒绝、经传输层回灌、同序号篡改内容；
- 链路涨价后全网改走次优路径，再叠加丢消息与旧价通告回灌仍正确；
- 分区显式不可达、分区内路由仍正确、重连且停丢后收敛；
- tick 0 初始通告全部被丢弃时，仅靠周期补发完成收敛。
- 过境排空：两种**独立受构搜索**（剪枝后定点松弛 / DFS 全枚举“中间点不含
  排空节点”路径）在 120 组随机图上互相一致，再核对：
  - 排空节点仍可作目的地、其余流量绕行、咽喉点排空时身后不可达、排空者自身
    仍可作起点、绕行并列按 (费用, 完整路径) 裁决；
  - 低序号及同序号异内容（资格位篡改）通告不能恢复旧资格，撤销后旧排空通告
    回灌无效；有损传输与分区下暂时分歧、停丢重连后收敛；
  - 非法事件不产生部分更新；不使用新事件时旧场景结构化输出逐字节不变。
